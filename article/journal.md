  - **Conclusion** : depuis une UDF ou une procédure Python, une règle `DATA_CONNECTIVITY_PROXY_EGRESS` se comporte comme une règle `EGRESS` ordinaire. Le trafic sort directement de Snowflake ; le tunnel n'est jamais utilisé. Les sources privées sont donc injoignables. C'est cohérent avec la doc (« available for use with Snowflake Openflow »).
  - **Effet de bord sécurité** : une règle « DCP » donne de fait une sortie Internet publique aux fonctions Python qui l'utilisent. Un nom DCP qui se résout publiquement vers autre chose que la cible privée serait joint en direct.
